# Modelo Jiu

O "Modelo Jiu" é um site simples desenvolvido para ajudar praticantes de Jiu-Jitsu a descobrirem sua categoria com base no ano de nascimento e no sexo. Através de uma interface simples, o usuário insere seu ano de nascimento e sexo, e o site retorna a categoria apropriada para competições, como "Adulto", "Master", entre outras.

## Como usar
1. Acesse o site.
2. Insira seu ano de nascimento e sexo.
3. A categoria de Jiu-Jitsu será exibida de acordo com os critérios da IBJJF.

## Tecnologias utilizadas

- CSS
- JavaScript
